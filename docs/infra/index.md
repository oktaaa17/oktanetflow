# Infrastructure Overview

Selamat datang di modul Infrastructure Oktanetflow.
Bagian ini dirancang untuk memberikan panduan praktis, konfigurasi sistem, dan implementasi infrastruktur mulai dari administrasi server bare-metal hingga virtualisasi modern dan shell scripting.

## Kategori Infrastruktur

Pilih modul pembelajaran infrastruktur sesuai kebutuhan:

- [Linux & Shell](/infra/linux/index)
  Panduan administrasi Linux, scripting Bash, otomasi Proxmox, konfigurasi SSH, dan setup Ubuntu Server.

- [Virtualisasi & Cloud](/infra/vm/index)
  Panduan praktis virtualisasi berbasis Proxmox VE, konfigurasi MikroTik CHR, Ubuntu Cloud image, dan otomatisasi backup.

- [Server Management](/infra/server/index)
  Panduan konfigurasi bare-metal server (Dell PowerEdge R620/R630), setup iDRAC, inisialisasi storage SSD/SATA, dan instalasi OS.

- [Hardware](/infra/hardware/index)
  Dokumentasi spesifikasi perangkat keras, pemeliharaan fisik, dan konfigurasi interface jaringan.

- [Software](/infra/software/index)
  Panduan instalasi software esensial pendukung laboratorium, OpenVPN client, partisi data, dan aplikasi teknis.

## Memulai Praktik

Gunakan navigasi sidebar untuk menjelajahi lab spesifik pada setiap kategori atau mulai dari [Linux Overview](/infra/linux/index).
