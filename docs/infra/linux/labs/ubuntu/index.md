# Ubuntu Server Labs

Modul ini berisi panduan praktis konfigurasi dasar dan administrasi Ubuntu Server untuk lingkungan server fisik maupun mesin virtual.

## Daftar Laboratorium

- [Lab 01: Quick Ubuntu 24.04 Configuration for Oldest Hardware](/infra/linux/labs/ubuntu/lab-01-quick-ubuntu-2404-configuration-for-oldest-hardware)
  Optimalisasi dan konfigurasi awal instalasi Ubuntu 24.04 LTS pada perangkat keras generasi terdahulu.

- [Lab 02: Change Root Password](/infra/linux/labs/ubuntu/lab-02-change-root-password)
  Manajemen akses pengguna dan prosedur penggantian password root dengan standar keamanan server.

- [Lab 03: Change Network and Nameserver](/infra/linux/labs/ubuntu/lab-03-change-network-and-nameserver)
  Konfigurasi Netplan untuk alokasi IP statis, gateway, dan pengaturan DNS nameserver pada Ubuntu Server modern.
