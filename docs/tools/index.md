# Interactive Tools & Utilities

Selamat datang di direktori Tools Oktanetflow.
Halaman ini menyediakan kumpulan utilitas praktis, kalkulator jaringan, dan alat bantu konfigurasi yang dirancang untuk mempercepat alur kerja teknisi jaringan dan sysadmin.

## Utilitas Tersedia

- [VLSM Calculator](/tools/vlsm)
  Kalkulator Variable Length Subnet Masking (VLSM) interaktif untuk merancang alokasi subnet IP secara optimal dan hemat alamat.

- [RDP Wrapper Setup](/tools/rdp-wrapper)
  Panduan dan utilitas setup Remote Desktop Protocol (RDP) multi-sesi untuk memfasilitasi akses remote di lingkungan lab.

- [Bootable USB Installer](/tools/bootable-usb)
  Panduan praktis pembuatan flashdisk bootable untuk berbagai sistem operasi menggunakan tool modern seperti Rufus.

## Integrasi Lanjutan

Tools tambahan dan visualisasi topologi interaktif sedang dikembangkan untuk mendukung simulasi lab langsung di peramban.
